# Support

Support and privacy pages for my apps, published via GitHub Pages at
https://maziac.github.io/support/

| App          | Support                                         | Privacy                                                      |
| ------------ | ----------------------------------------------- | ------------------------------------------------------------ |
| PingAll      | https://maziac.github.io/support/pingall/       | https://maziac.github.io/support/pingall/privacy.html        |
| The Archiver | https://maziac.github.io/support/the-archiver/  | https://maziac.github.io/support/the-archiver/privacy.html   |

## Structure

One folder per app (`index.html`, `privacy.html`, `style.css`, `icon.png`).
All links inside a folder are relative. `index.html` in the root lists all apps.
To add a new app, create a folder and add it to the list in `index.html` and this README.
